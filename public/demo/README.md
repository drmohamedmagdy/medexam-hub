# Landing-page demo videos

Drop short looping MP4 / WebM clips here and they'll render on the
home page automatically. Each clip should be 6–15 seconds, **muted**
in source (autoplay requires it), and ideally < 2 MB.

| File             | Where it shows               | Recommended size            |
|------------------|------------------------------|-----------------------------|
| `hero.mp4`       | Hero "Watch demo" lightbox   | 1280×720, 12–20s            |
| `hero-poster.jpg`| Hero video poster image      | 1280×720                    |
| `exams.mp4`      | "See it in action" — Exams   | 720×900 (portrait), 6–10s   |
| `research.mp4`   | "See it in action" — Research| 720×900 (portrait), 6–10s   |
| `statistics.mp4` | "See it in action" — Stats   | 720×900 (portrait), 6–10s   |
| `library.mp4`    | "See it in action" — Library | 720×900 (portrait), 6–10s   |

Optional matching `*-poster.jpg` files are rendered before the video
loads on slow connections.

If a file is missing the page degrades gracefully — the corresponding
card will show a still gradient with the feature title. No broken
images.
